# 台灣彩券與運動彩券研究

研究台灣的威力彩、大樂透、其他台彩遊戲和運動彩券：規則是什麼、過去的資料說了什麼、有沒有辦法「買得比較聰明」。這份 README 是結論和決策劇本；證據和計算細節在 [docs/](#詳細研究)。

## 先記住五件事

1. **樂透號碼沒辦法預測。** 4,000 多期開獎完全符合純隨機；熱號、冷號、AI、明牌、9 種機器學習方法全部試過，沒有一個比亂猜好。
2. **能改變的只有「中了要跟幾個人分」和「這期划不划算」。**
   - 選冷門號（大號、打散、避開圖案）：大樂透中頭獎時，要分獎金的人數從最多 3 倍降到 0.35 倍。
   - 只在頭獎池破線時買：威力彩約 22 億、大樂透約 6.5–10 億才會平均不虧，18 年來只有 16 期。
3. **就算划算，你還是幾乎一定輸。** 頭獎機率是 1/1,400 萬到 1/2,200 萬。「划算」只是平均不虧，不代表你會中。
4. **所有彩券平均都虧。** 每花 100 元平均拿回：威力彩 38 元、大樂透 50 元、49樂合彩二合 64 元、高面額刮刮樂 67–75 元、運彩單場 86 元；加碼期間最高約 83 元。運彩 5 萬場歷史資料裡，沒有任何固定押法長期不虧。
5. **靠「跟別人不一樣」賺到的好處，太多人照做就會消失**（見[前提](#這份劇本的前提只有少數人照做)）。固定獎金的遊戲、少買、隨機選號，這幾條不管多少人照做都成立。

> 一句話：平常不買；想玩買大樂透、選冷門號；加碼活動或頭獎破線時才買 1–2 注；明牌一律不理。

## 劇本 A：平常想買一點當娛樂

- **情況**：沒有加碼，頭獎池一般（大樂透 1–5 億、威力彩 2–15 億）。
- **決策**：
  1. 買**大樂透**，不要買威力彩。同樣 100 元，大樂透頭獎機率高 3.2 倍，平均拿回 50 元，威力彩只拿回 38 元。
  2. 每期最多 1–2 注，把它當娛樂費，錢花掉就算了。
  3. 號碼照劇本 G 選。
- **為什麼**：這種時候每花 100 元平均虧 50–62 元，買越多虧越多。

## 劇本 B：春節或節日加碼

- **情況**：台彩辦加碼活動。例如 2026 年春節，大樂透連開 20 天，每期另外加開「大紅包」（100 萬）和「小紅包」（10 萬），同一注自動對獎，不用另外付錢。
- **決策**：
  1. 一年如果只買幾次，**就挑這時候買大樂透**。
  2. **活動開始後前幾天就買。** 大紅包總數有上限（2026 年是 480 組），發完活動就提前結束。
  3. 號碼選冷門的（劇本 G）。紅包也是多人中同一組就平分。
- **數字**：每注平均多拿回約 9–10%（冷門號約 10.5%）。大樂透平均回收從 50% 變成約 60%，**還是虧**，只是虧得最少。

## 劇本 C：頭獎池暴漲

- **情況**：頭獎連續好幾期沒人中，彩池滾大，新聞開始報導。
- **門檻**（頭獎池超過這個數字，平均來說才不虧）：

  | | 買的人普通 | 買的人暴增 6 倍 | 選冷門號時 |
  |---|---|---|---|
  | 大樂透 | 6.4 億 | 9.7 億 | 6.1–7.1 億 |
  | 威力彩 | 21.8 億 | 23.4 億 | 21.6–22.7 億 |

  彩池越大，跟風買的人越多，中了要跟別人分的機會也越大，所以門檻會往上移。新聞一直報導時，就用「暴增」那一欄。

- **決策**：
  1. 過線就可以買，**但只買 1–2 注**。依凱利公式（算「一次該押多少錢」的方法），中獎機率只有一千多萬分之一時，就算平均不虧，也只該押總資產的一億分之一左右。
  2. 一定要選冷門號（劇本 G）。這時候跟風的人最多，選熱門號很可能要跟好幾個人分。
  3. 過去 18 年過線的期數：大樂透 2,069 期中 13 期（選冷門號時 44 期），威力彩 1,949 期中 3 期（選冷門號時 8 期）。**一年大概只有一兩次。**
- **不要做**：因為「這期划算」就大量買。買 1,000 注中頭獎的機率也才 1/14,000，幾乎一定全部賠光。

## 劇本 D：想常常中點小獎

- **情況**：不追頭獎，只想每次花錢都比較不虧。
- **決策**：
  - **高面額刮刮樂**：平均回收約 67–75%，面額越高越不虧（2026 年的 2,000 元款每 100 元平均虧 25 元）。大部分獎金是 5,000 元以下的小獎，不用扣稅。
  - **49樂合彩二合**：每 100 元平均拿回 64 元，是電腦彩券平常最高的；獎金 1,250 元，不用扣稅。
  - 端午、中秋前後 **39樂合彩二合**常加碼到 1,500 元，回收率約 81%（2020 年以來有 19 個月份）。
  - **賓果加碼**（例如 2026 春節 3星中 3 個給 40 倍）回收率約 83%，但每 5 分鐘開一次，設好總預算，花完就停。
- **不要做**：
  - 挑「頭獎還沒開出、快賣完」的刮刮樂款。台彩要等那款停賣後才公布賣了多少、頭獎還剩幾張，事前算不出來。
  - 今彩539、樂合彩三合／四合：回收率 0.39–0.48，跟威力彩、大樂透差不多或更差。

## 劇本 E：各種傳言、明牌、玩法

| 聽到的說法 | 怎麼做 |
|---|---|
| 「這號最近很熱，會繼續開」 | 忽略。上期開出的號碼，這期再開出的機率跟理論值一樣（15.6% 對 15.8%）。 |
| 「這號很久沒開，快開了」 | 忽略。冷號策略在回測裡跟亂猜一樣。 |
| AI、明牌、預測軟體 | 忽略。9 種 ML 方法全部沒有贏過亂猜；真的有效的話，他不會拿來賣你。 |
| 包牌 | 不會變划算，只是一次買很多注。中獎機率＝注數 ÷ 總組合數。 |
| 合買 | 可以玩。平均拿回的錢不變，只是分攤成本。**要事先把誰出多少錢寫下來**，不然中獎後分錢可能被課贈與稅。 |
| 「電腦選號比較會中」 | 不會。頭獎得主有七成用電腦選號，是因為買的人本來就有七成用電腦選號。不過電腦選號不會偏向生日號，這點比自己亂選好。 |
| 全部組合都買下來 | 做不到。大樂透要 6.99 億、威力彩要 22.1 億，還要在開獎前印出 1,400 萬到 2,200 萬張彩券。 |

## 劇本 F：中獎了

1. **先在彩券背面簽名**，拍照留存，放在安全的地方。
2. **5,000 元以下**：在任何彩券行直接換現金，不扣稅。
3. **超過 5,000 元**：扣 20% 所得稅和 0.4% 印花稅，實拿 79.6%。依金額到指定的銀行分行，或中國信託總行領獎；超過 500 萬要先打電話預約。
4. **兌獎期限**：開獎隔天起 3 個月，過期就作廢。
5. 如果是合買，照事先寫好的比例分錢，保留分錢的紀錄。

## 劇本 G：怎麼選號（樂透都適用）

1. 最簡單：直接跑 `python src/lottery/pick.py lotto 2`（威力彩改成 `power`），它會隨機給你偏冷門、又不是圖案的號碼。
2. 要自己選的話：
   - **多選大號**：大樂透 40–49、威力彩 31–35 最少人選。
   - **少選 1–12**：月份、生日、幸運數字，最多人選。
   - **避開圖案**：連續 3 個以上的號碼、等差數列（像 5 10 15 20…）、6 個號碼都在同一個十位數，都有很多人故意買。
   - **避開上期開出的號碼、新聞明牌、「最熱門號碼」排行榜。**
   - 威力彩第二區選哪個都差不多，1 號最少人選，但只少 6%。
3. 選不出來就用電腦選號，至少不會偏向熱門號。
4. 效果（大樂透）：中頭獎時，冷門組合平均只要跟 0.35 倍的人分，熱門組合要跟 3 倍的人分。**中獎機率完全一樣，差別只在中了以後分到多少。**

固定獎金的遊戲（賓果、樂合彩、3星彩、4星彩）獎金不用跟別人平分，選冷門號沒用。

## 劇本 H：運動彩券

| 情況 | 決策 |
|---|---|
| 想買運彩 | 只押**單場**，每押 100 元平均發回 86 元，比所有樂透都好。 |
| 想串關拚大的 | 不要。2 串只發回 74%，4 串只剩 55%。 |
| 有自己的看法 | 先去查國際盤口。**運彩盤口跟國際盤口差很多時，只押國際盤看好的那一邊**，虧損從 13% 降到約 4.5%，但長期還是虧。 |
| 想長期靠運彩賺錢 | 幾乎不可能。賠率 1.75 要猜中 57% 以上才打平，比職業玩家的程度還高。 |
| 都押冷門、都押熱門、都押大分、都押小分 | 5 個聯盟、5 萬場的資料都顯示這些押法全部虧，押大分最虧。 |

## 這份劇本的前提：只有少數人照做

- **冷門號的好處很容易被用完。** `pick.py` 選到的冷門號大約占所有組合的 5%。只要大約 2%（大樂透）或 1.3%（威力彩）的彩券都照它選，這些號碼中了要跟幾個人分，就會跟隨機選的號碼一樣多，好處歸零。
  - 如果 10% 的人照做，中了要跟 2.7–2.9 倍的人分，跟現在最熱門的號碼差不多擠（2.1–3.1 倍）。
  - 如果大家都照做，唯一的穩定解是「每個人都用電腦完全隨機選號」，沒有人佔便宜。
- **「只在頭獎池破線時才買」要靠別人先輸錢。** 頭獎池是每期銷售額的一部分累積起來的（威力彩約 30%，大樂透約 22%）。威力彩頭獎池要從 2 億滾到 22 億，前面得先有人買掉約 66 億元不划算的彩券；大樂透從 1 億滾到 10 億要先有約 40 億元。如果大家都等破線才買，彩池根本滾不大。
  - 就算真的破線，所有人一起湧進來，撞號的人暴增，平均拿回的錢又會掉回 1 元以下。美國麻州的 Cash WinFall 就發生過：合買團專挑划算的期數大量買，把利潤吃光，那款遊戲在 2012 年停辦。
- **把所有買彩券的人加起來，一定是虧的。** 大約 55–60% 的錢發回給中獎的人，其餘用在公益、佣金和營運。會有「划算的期數」，只是因為前幾期的人輸掉的錢累積到了這一期。

## 重現

需要 Python 3.12 和 [uv](https://docs.astral.sh/uv/)。Windows 終端機若出現編碼錯誤，先設 `PYTHONIOENCODING=utf-8`。

```
# 台彩
python src/lottery/fetch.py                                                        # 下載全部遊戲；也可指定：power lotto d539 m539 m649 d3 d4
uv run --with numpy,scipy,pandas,scikit-learn python src/lottery/analysis.py       # 隨機性＋熱門度＋期望值 → output/analysis.json
uv run --with matplotlib,numpy python src/lottery/charts.py                        # 圖 → output/fig_*.png
uv run --with numpy,scipy,scikit-learn,lightgbm python src/lottery/ml_backtest.py  # ML 回測 → output/ml_results.md（約 1.5 分鐘）
uv run --with numpy,scipy python src/lottery/second_zone.py                        # 威力彩第二區熱門度
python src/lottery/other_games.py                                                  # 其他遊戲回收率
python src/lottery/pick.py lotto 5                                                 # 冷門選號（lotto 或 power）

# 運彩
python src/sports/scrape.py MLB 2019-03-01 2026-09-27    # 抓歷史賠率（MLB/NBA/NPB/CPBL/KBO；每秒 1 頁；可中斷續抓）
uv run --with numpy,scipy python src/sports/analyze.py   # 分析 → output/sports.json
```

`ml_backtest.py` 另外會輸出約 26 MB 的 `output/ml_results.json`（逐期預測明細），研究報告沒用到，不保留。
