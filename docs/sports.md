# 運動彩券（台灣運彩）研究

[← 回總覽與決策劇本](../README.md)

程式：[src/sports/scrape.py](../src/sports/scrape.py)（抓資料）、[src/sports/analyze.py](../src/sports/analyze.py)（分析），完整數字在 [output/sports_stdout.txt](../output/sports_stdout.txt)。

**資料**：玩運彩（playsport.cc）「賽事結果查詢」頁公開列出每場比賽的運彩最終賠率（讓分、不讓分、大小）、國際盤口和比分；它的 robots.txt 全站允許抓取。一共抓了 **52,275 場**：MLB 2019–2026（另有 2015 年的一小段）、NBA 2019–2026（另有 2015 年的一小段）、日職 2015–2026、中職 2015–2026、韓職 2022–2026，展開後有 27 萬筆單注。運彩官網有 Cloudflare 防護，只查得到當下的賠率。

**規則重點**
- 法律規定獎金最多發回 78%。
- 賠率 500 倍以下的單注不扣所得稅，超過 5,000 元只扣 0.4% 印花稅。
- 有些比賽不能單場下注，至少要跟另一場串在一起（2 串 1 以上）。

| 發現 | 數字 |
|---|---|
| **運彩每押 100 元平均發回多少** | 二選一的玩法約 86–87 元，**2024 年起再降到 85–86 元**；足球、冰球這類三選一玩法約 79–84 元（2026-09-28 官網快照）。國際大型賭盤約 97–98 元。 |
| **每一場每一種玩法全部都押** | 27 萬筆，實際報酬 **−13.4%** |
| 固定押法（熱門、冷門、主隊、客隊、大分、小分、依賠率分組） | 5 個聯盟共 122 個檢定，**沒有一個不虧**，校正多重比較後也沒有顯著的。虧最少的是押讓分盤的冷門隊（日職 −6.8%、MLB −8.3%）和押小分（約 −11～−12%）；押大分最虧（約 −14～−17%）。 |
| 運彩的大小分盤口跟國際盤口差 1 分以上時，**照國際盤看好的那邊押** | 5,578 筆，**−4.5%**；反著押是 −21.8% |
| 串關 | 每多串一場，發回比例就再乘上約 0.86：2 串約 0.74，3 串約 0.64，4 串約 0.55 |

**白話結論**
1. **運彩比樂透好一點，但還是虧。** 單場平均發回 86%，比樂透的 38–64% 高，但莊家先抽 13–15%。國際賭盤只抽 2–3%，運彩大約是它的 5 倍。
2. **國際盤口確實有參考價值，但不夠贏過抽成。** 運彩盤口跟國際盤口差很多時，照國際盤的方向押，虧損從 13% 降到約 4.5%；反著押則虧到 22%。這表示國際盤比運彩準，只是差距還填不滿運彩的抽成。
3. **要長期贏運彩，勝率得比國際盤還準。** 賠率 1.75 時，要猜中 57.1% 才打平。職業玩家對國際賭盤通常只能做到 52–54%。
4. **串關虧得最快。** 抽成會一關一關疊上去，4 串的期望回收只剩一半多。
5. **抽成在變高。** 2024 年起，各聯盟的發回比例都掉了約 1 個百分點。

**限制**
- 玩運彩頁面上的是賽前最後的賠率，沒辦法測「開盤就搶先下注」這類策略。
- 國際盤口只有盤口，沒有賠率，所以只能比較盤口差多少，算不出準確的公平機率。
- NHL 的頁面欄位格式不一樣，沒有納入。
